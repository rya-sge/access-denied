# SSZ vs RLP: verification

Code behind the article `_posts/2026-11-04-ssz-vs-rlp-ethereum-serialization.md`. Test code: not audited, do not deploy.

## What is tested

| Script or test | Claims that depend on it |
|----------------|--------------------------|
| `python/check_vectors.py` | Both codecs agree with upstream vectors; the fuzz results on canonical encoding |
| `python/check_mainnet.py` | Byte-identical beacon block, block root, block hash, transaction hashes, MPT roots, block size, the two withdrawal and transaction roots |
| `python/examples.py` | Every byte-level example and both strictness tables |
| `python/measure_sizes.py` | The size, calldata and zlib table, proof sizes |
| `python/measure_hashing.py` | Flat hashing against `hash_tree_root`, the 39-hash update |
| `test/Decode.t.sol` | Every Solidity gas figure, and parity between the readers and the Python values |

## How to run

```sh
./run_all.sh
```

Python needs only the standard library and runs with `python3 -I`, so each script adds its own directory to `sys.path`. `measure_hashing.py` takes a few minutes. Foundry uses no `forge-std`: `test/Decode.t.sol` declares a minimal `Vm` interface. `foundry.toml` pins solc 0.8.30 and EVM version `osaka`. `fixtures/` and `test/Expected.sol` are generated by `python/gen_fixtures.py`.

## Gas method

Each figure is the gas of a warm `staticcall` minus that of a no-op with the same calldata, so it excludes intrinsic calldata cost. Figures labelled gross include the call. The readers favour clarity, so ratios are specific to them.

## Limits

- `eip6404.py` is a reading of a Draft EIP. No upstream vector exists for it.
- In `fixtures/txs_rlp.hex` each transaction is an RLP string, legacy ones included, so both lists hold identical elements. A real block body writes legacy transactions as nested lists.
- zlib stands in for Snappy, which the standard library lacks.
- A fetch of one full epoch was planned and not run, so size ratios come from one block.
