Two layers of Linux. The security layer covers the primitives an attacker and a defender both work with: authentication, permissions, ACLs and file attributes, namespaces and isolation, SECCOMP filtering and the Linux Security Modules on top of it.

The practical layer is older and mostly in French: SSH access, hard and symbolic links, backups, and intrusion testing against a running service.
