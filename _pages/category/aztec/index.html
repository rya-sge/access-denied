Articles on Aztec, a privacy-focused Layer 2 on Ethereum where a contract has a private half proved on the user's own device over encrypted notes, and a public half executed by a sequencer. They cover the execution model itself, notes and nullifiers, how an address doubles as an encryption key, where randomness and ephemeral keys come from, and what the chain publishes of a private transaction.

The contract-writing side runs through Noir: code reuse without inheritance, packing values into a field, reading public state from a private function and the delay that costs, partial notes, the AIP-20 token standard next to ERC-20, and what a private function costs in proving gates. Several of them are written from a working privacy-preserving CMTAT security token, so the examples are measured rather than hypothetical.
