The machine learning fundamentals come first: supervised and unsupervised learning, gradient descent, k-nearest neighbours and recurrent neural networks. The security questions follow, once a model is deployed and someone has a reason to abuse it.

Agents on-chain make up the rest. The ERC standards here give an autonomous agent an identity, a reputation and a way to be validated, and one article covers the safeguards built into agent tooling such as Claude Code.
