{%- comment -%} Series navigation box, rendered under the article title when the post declares a `series:` key. Nothing renders for a post that does not. The series themselves are declared in `_data/series.yml`, which carries the display title and whether the group has a reading order: * ordered - "Part N of M", numbered list, sorted by each post's `series_order:` front matter. * unordered - "N articles in this series", plain list, newest first. Used where the articles share a subject but no intended order (four independent studies of one protocol, write-ups of separate contests). Numbering those would tell the reader to start at a place the author never chose. Two things this buys beyond navigation: every article in a series links to every sibling, which is the densest topical internal linking on the site, and the CreativeWorkSeries / hasPart block below states the relation explicitly rather than leaving a crawler to infer it from title prefixes. {%- endcomment -%} {% if page.series %} {% assign series = site.data.series[page.series] %} {% if series %} {% assign t = site.data.i18n[page.lang] | default: site.data.i18n.en %} {% assign members = site.posts | where: "series", page.series %} {% if series.ordered %} {% assign members = members | sort: "series_order" %} {% else %} {% assign members = members | sort: "date" | reverse %} {% endif %} {%- comment -%} Position of the current article inside the series. {%- endcomment -%} {% assign position = 0 %} {% for member in members %} {% if member.url == page.url %}{% assign position = forloop.index %}{% endif %} {% endfor %}
